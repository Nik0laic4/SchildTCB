# Code of Conduct

Schild TCB is a single-author research project, but contributions, issues, and
discussions are welcome. We ask everyone to keep the space constructive,
respectful, and technically focused.

## Expected behaviour

- Be respectful and welcoming in issues, pull requests, and discussions.
- Give and accept constructive technical feedback gracefully.
- Focus on code, evidence, and reproducible results rather than people.

## Unacceptable behaviour

- Harassment, discrimination, or personal attacks.
- Trolling, sustained disruption, or derailing technical discussion.
- Publishing others' private information without permission.

## Scope

This code of conduct applies to all project spaces (GitHub issues, pull
requests, discussions) and to public communication about the project.

## Enforcement

The project maintainer is responsible for enforcement. To report a violation,
contact the maintainer privately (see the git author or `SECURITY.md`). Reports
will be handled confidentially.
