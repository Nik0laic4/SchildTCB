# Schild TCB — Сверка нашего virtio-net с L4Re (архитектурно)

**Version:** v1.0 | **Date:** 2026-10-25
**Status:** аналитическая сверка принципов (не построчный diff — точный путь к L4Re-драйверу
не выкачивался; сравнение по документированной архитектуре L4Re io-сервера).

## Наш подход (virtio-net под seL4)

- **Per-device child-домен** — драйвер + протокол в отдельном ELF-child со **своим VSpace** и CSpace.
- **Hand-rolled split-virtqueue** — RX-пул + ротация TX, рециклинг через used-ring по `id`.
- **IRQ** — `IRQControl_Get` → badged Notification → waiter-TCB (`seL4_Wait`) → Ack → signal.
- **Фиксированная раскладка** — MMIO/DMA на фиксированных VA; root инициализирует → child re-attach.
- Минимально: **без** generic virtio core, **без** PCI (только MMIO-транспорт).

## Подход L4Re (Fiasco.OC + L4Re)

- **Монолитный io-сервер** — один домен владеет всеми устройствами (PCI/MMIO/IRQ/DMA) и отдаёт
  их клиентам через «виртуальную шину» (`Hw::Device`/`Io`).
- **Generic virtio core** (`Virtio::Device`) + абстракция транспорта (PCI **и** MMIO).
- **IRQ** — через `icu` (interrupt controller) + IRQ-объекты io-сервера.
- **DMA** — через `L4Re::Dma_space` с **ограничениями адресов** (аллокатор учитывает окна устройств).
- Драйвер ↔ клиент — IPC через io-сервер.

## Вывод (что берём / что нет)

| Аспект | Оценка |
|---|---|
| Изоляция | Наш **сильнее**: per-device VSpace; у L4Re все драйверы в одном io-домене |
| Сложность | Наш **проще**: нет generic virtio core и PCI |
| **DMA-space с ограничениями** | **Перенять** — напрямую пригодится для GENET («нижний 1 ГБ») |
| **Транспорт vs устройство** | **Перенять при необходимости** — если позже добавим PCI |
| Монолитный io-сервер | **Не перенимать** — у нас лучше |
| Generic virtio core | **Не перенимать** — избыточно для нашего масштаба |

**Итог:** наша реализация не уступает L4Re по принципам (и выигрывает по изоляции).
Заимствовать из L4Re стоит только две абстракции — **DMA-аллокатор с адресными окнами**
(нужно для GENET) и, опционально, разделение «транспорт/устройство».
