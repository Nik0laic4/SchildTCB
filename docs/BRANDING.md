# Schild TCB — брендинг и визуальный язык

Идея знака: **доверие, завершённое доказательством**. Проект не просит «поверьте
нам», а ставит ∎ (символ Халмоша, U+220E, «end of proof»).

## Почему ∎ (QED)

Классический щит говорит «security» без единой буквы; внутри — канонический знак
завершённого доказательства, каким он печатается в математической литературе с
1950-х. Знак читается дважды:

- для обычного читателя (рекрутера) — строгий, понятный «щит безопасности»;
- для математика или инженера по формальным методам (AdaCore, seL4) — мгновенный
  триггер «здесь понимают, что такое доказательство».

Это не декоративный ход, а честная метафора самого проекта: различие «proved vs
contained» из модели угроз здесь сведено к одному глифу — ∎ внутри щита.

## Палитра (совпадает с цветами отчётов)

- `#0B1C2C` — структура / Ring 0 (контур щита).
- `#2FA5A0` — formally proved (∎, Tier A).
- `#6B7A8F` — contained, не proved (пунктир, Tier B).
- `#E0A458` — изолированная периферия (NetServer).

## Варианты знака

1. **Schild ∎** (щит + ∎) — основной знак. favicon, угловой штамп документов,
   моно-версия для одноцветной печати.
2. **Wordmark** (щит + «Schild TCB») — горизонтальный локап для шапок: плотный
   жирный «Schild» (вес, надёжность) и разреженный лёгкий «TCB» (инженерная
   аббревиатура).
3. **Proved Core** (кольца ярусов) — архитектурная диаграмма, не логотип: сплошное
   внутреннее кольцо = Tier A (proved), пунктирное среднее = Tier B (contained),
   внешний контур = граница доверия Ring 0, квадрат на периферии = изолированный
   NetServer. Пунктир честнее сплошной линии: contained ≠ proved.
4. **Gate Pass** (гексагон + галка) — дружелюбный вариант для UI-панелей и
   маркеров «proved» в таблицах.
5. **Proof Ledger** (круглая печать с 24 рисками) — торжественный вариант для
   релизов и обложек.

## Геометрия ∎

Пропорции ∎ не придуманы — они измерены по реальному литерному глифу ∎ шрифта
DejaVu Sans (138×194, w/h 0.711); в логотипе — 124×176 (0.705). Расхождение 0.006.
